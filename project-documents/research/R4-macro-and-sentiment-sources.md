# R4 — Macro and Sentiment Sources (Research)

Date: 2026-09-07. Compiled by fetching official docs/pricing pages where possible; secondary sources used and marked where a direct fetch was blocked (403 / bot-gated).

## 1. Executive Summary

- **Macro (Part A):** FRED is the correct backbone for nearly every series requested (DXY proxy, VIX, 2s10s, Fed funds, SOFR, real yields, CPI, S&P 500, Nasdaq) — it is free, keyed, rate-limited to 120 req/min, and each series page publishes its own release lag. The critical finding: **lag varies by two orders of magnitude across "macro."** SOFR/DFF/VIX/T10Y2Y/SP500/NASDAQCOM update same-day-to-next-day; DFII10 (real yields) and DTWEXBGS (Fed's own trade-weighted dollar index) lag 1–3 business days; **CPI and M2 lag 3–5 weeks** and are the ones a dashboard must flag as stale-by-design, never "live." There is no true ICE DXY on FRED — only the broader, methodologically different DTWEXBGS (26 currencies vs. DXY's 6). yfinance/Yahoo unofficial endpoints still work in 2026 but are undocumented, break silently (Feb 2025 site redesign already broke widely-used scrapers), and carry no SLA — acceptable as a free fallback, not as a sole source.
- **Flows/structural (Part B):** No official machine-readable BTC/ETH ETF flow API exists for free. Farside is the de facto free standard but is an HTML table with no published API (aggregators re-scrape it); SoSoValue has a genuine free "Demo" API (rate-limited, beta); Coinglass bundles ETF flows into a free web tier and a ~$29+/mo API. All of these report T+1 (US ETF issuers/custodians report the prior day's creation/redemption after market close; nothing is same-day). DefiLlama's stablecoin API is free, keyless, and covers per-chain circulating supply/net issuance. BTC dominance **is not a single number** — CoinGecko and CoinMarketCap differ by 1–2 percentage points because they disagree on what counts as "circulating supply," and both fold stablecoins into total market cap, which mechanically depresses the printed BTC.D.
- **Sentiment (Part C), judged adversarially:** Most of this category should not ship. The Fear & Greed Index (alternative.me) has zero published predictive-validity evidence — it is explicitly a descriptive, backward-looking composite (with a Bitcoin-dominance sub-input and a Google Trends sub-input, meaning it is not independent of what a dashboard would already show elsewhere). CoinMarketCap runs a **different, proprietary** Fear & Greed with different weights — displaying both as if they were two independent votes reproduces exactly the double-counting failure documented in the platform's history. pytrends is now archived/dead (frozen since April 2025) and Google's official Trends API is gated alpha with no public access — this is the same failure mode that pushed the prior system onto 4chan thread counts and should not be repeated with another scraped substitute. X API has no free tier as of Feb 2026 (pay-per-use, ~$0.005/read); Reddit's free tier still exists (100 qpm, non-commercial) but every new OAuth client now requires manual approval (weeks). CryptoCompare/CCData retired its free tier entirely on 2026-05-21. Academic evidence on social-sentiment predictive validity for crypto is real but thin, mixed, mostly in-sample/backtested, and never validated for the specific vendor feeds (LunarCrush, Santiment) a hobby dashboard would actually buy — it exists for generic Twitter text-sentiment research, not for any specific commercial product. Funding rate is the one "sentiment" proxy with a direct, non-scraped, always-fresh, verifiable source (the exchange itself) and modest but real published predictive evidence (~12.5% of 7-day variance in one study, cross-sectional use stronger than single-asset).

**API access notes:**
- **FRED**: free, requires API key (instant self-serve registration), **120 requests/minute** per key, no published hard daily cap. Best-documented release lag of any source in this table because every series page states its own next-release date. [fred.stlouisfed.org/docs/api/fred/]
- **yfinance / Yahoo unofficial endpoints**: still functional in 2026 but explicitly unofficial — Yahoo's Feb 2025 site redesign broke widely-used scraping patterns, rate limits are undocumented and IP-based, and there is no SLA. Fine as a free fallback for equity/FX/index quotes; do not rely on it as the only path for anything shown as "live."
- **Alpha Vantage**: free tier is **25 requests/day, 5/min** — too thin for a live multi-series dashboard refreshed more than a couple of times a day. Paid tiers start at $49.99/mo (75 req/min, no daily cap).
- **Twelve Data**: free tier **800 calls/day, 8/min**, free-tier data carries a 1–15 min delay depending on exchange. Paid Grow plan $29/mo (55 req/min).
- **Polygon.io** (rebranded **Massive.com** in July 2026, same API/keys): free Basic tier is 5 calls/min with 15-min-delayed EOD stock/index/forex data and 2 years history; Starter $29/mo removes the call cap but data is still 15-min delayed.
- **Nasdaq Data Link (Quandl)**: free with API key — 300 calls/10s, 2,000/10min, 50,000/day; hosts FRED mirrors and other free datasets; premium datasets priced à la carte.
- **Stooq**: free CSV endpoint (`stooq.com/q/d/l/`), no official terms-of-service doc found; as of early 2026 requires a CAPTCHA-obtained key and enforces an undocumented daily quota ("Exceeded the daily hits limit"). Treat as best-effort free, not contractually reliable.
- **TradingEconomics**: no meaningful free tier for API use (trial capped at 100 requests/100k datapoints, non-refundable, auto-converts to paid). Paid Standard plan ≈ $149/mo, Professional ≈ $299/mo (third-party reporting; TradingEconomics gates its own pricing page behind login — **UNVERIFIED** exact current figures, treat as approximate).
- **EOD Historical Data (EODHD)**: free tier is a thin 20 calls/day. Macro-specific product line starts at €19.99/mo (EOD all-world) up to €99.99/mo (all-in-one); macro indicators endpoint sources World Bank WDI data, refreshed annually — **not suitable for anything needing better than annual freshness.**

## 5. $0 / Under $50 / $50–200 Recommendation

**$0 (recommended baseline):**
- Macro: FRED (all series in the table above) + Stooq for gold as a gap-filler.
- Flows: SoSoValue free Demo API for ETF flows (T+1, labeled as such); DefiLlama for stablecoins; CoinGecko free Demo API for dominance/market cap (pick one provider, stay on it).
- Structural: exchange-native funding-rate endpoints (free).
- Sentiment: alternative.me Fear & Greed (labeled as a composite, not a signal) + CryptoPanic free news feed (headlines only, votes labeled as "CryptoPanic users," not "market"). That's it.

**Under $50/mo (optional upgrades, not required for trust):**
- Twelve Data Grow ($29/mo) or Alpha Vantage Basic if FRED/Stooq/yfinance prove too flaky for equity-index cross-references.
- Santiment $49/mo **only if** the real-time (non-30-day-lagged) social-volume number is specifically wanted — and even then, disclose the lack of vendor-specific validity evidence in the UI, don't imply it's been proven predictive.

**$50–200/mo (not recommended for this single-user dashboard):**
- Coinglass API, CryptoQuant, Polygon/Massive Starter, TradingEconomics Standard — all provide real value (exchange reserves, CME basis, Coinbase premium, cleaner macro cross-checks) but none are necessary to hit the product's actual goal (sourced, staleness-aware, non-composite display). Revisit only if a specific $0-tier source breaks and there's no other free substitute.
- X API pay-per-use and Reddit commercial tier: excluded regardless of budget tier — wrong access model/evidence base, not just a cost problem.

## 6. Recommended Omissions (with reasons)

1. **CoinMarketCap Fear & Greed Index** — duplicate construct of alternative.me's index under a different, less-transparent methodology; displaying both reproduces the exact "counted twice, correlation 0.72 with itself" failure this project already identified and removed once.
2. **Google Trends / pytrends (in any form)** — pytrends is dead (archived April 2025); the official API is not publicly available; any scraped substitute repeats the fragility that originally caused the fallback to 4chan thread counts.
3. **LunarCrush and Santiment sentiment endpoints at the $0 tier** — the actually-useful (real-time) parts are paywalled, and no vendor-specific predictive-validity evidence exists to justify paying for them on a personal dashboard.
4. **X/Twitter sentiment** — no free access tier exists as of Feb 2026; the academic evidence that does exist is for generic researcher-scraped text, not for a purchasable feed; wrong cost/evidence shape entirely.
5. **Reddit sentiment** — technically free but now gated behind a multi-week manual OAuth approval process, making it operationally impractical for a personal project; also has no source-specific validity evidence.
6. **CryptoCompare/CCData (CoinDesk Data)** — free tier retired outright (2026-05-21); no public pricing remains.
7. **4chan /biz/ thread counts, any halving-cycle-position indicator, and any spx_correlation-style locally-derived indicator** — explicitly not to be reintroduced; the original documentation already labeled the 4chan substitution "unvalidated," the halving-position indicator "meaningless," and the SPX correlation was empirically **inverted** over 1,394 days. None of the new research above surfaces evidence that changes those prior conclusions.
8. **News-API sentiment scores generally (Marketaux, CryptoPanic votes, any TextBlob-derived score)** — keep news as *headlines with timestamps and sources* (useful, verifiable, low-risk); drop any accompanying "sentiment score," since none of these vendors publish external validity evidence for their scoring and a crowd-vote count (CryptoPanic) is not a market signal.
9. **CMC/CoinGecko dominance shown side-by-side or averaged** — pick one, disclose the methodology gap, never blend two disagreeing numbers into a single displayed figure.
